# Coffee Machine
This was a project for my second-year Java programming module.

## About the Project
Upon running it, this program displays a menu with three options:
1. Order Coffee
2. Switch Language
3. Exit

Inputting 1 displays another menu for the user to select what type of coffee they want to order.
The three coffee options are:
- Americano
- Espresso
- Latte

Once the user types in what coffee they want, the program "prepares" the coffee and plays a sound
clip of the selected coffee being poured. It also counts the seconds it takes to "prepare" the coffee.
It then displays the first menu again.

Inputting 2 switches the language between English and Japanese, so the menus will display in whatever
language has been selected.

Inputting 3 exits the program.
